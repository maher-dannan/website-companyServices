# Help and Inspiration

## Page Structure

Choose a one-page website or a website with subpages. A possible structure:

- **Header** with a title or name
- **Introduction** with a short overview or a large image/gallery
- **Main content** with information
- **Contact or closing section**
- **Footer** with additional information

## Website Inspiration

Have a look at a few websites and pay attention to things such as:

- Which colours are used?
- How is the content arranged?
- How much space is there between the elements?
- Which fonts, images, or animations stand out to you?

You do not have to copy an entire website. A layout, a colour scheme, or a single element is often enough to provide inspiration.

- [One Page Love](https://onepagelove.com/inspiration) – websites that consist of a single page
- [Land-book](https://land-book.com/) – lots of different websites and styles
- [SiteInspire](https://www.siteinspire.com/) – discover websites by style and topic
- [Awwwards](https://www.awwwards.com/) – unusual designs, effects, and animations

## Create a Design Quickly

1. Find a website to use as rough inspiration.
2. Choose a colour palette.
3. Choose a font and, if needed, images or icons.
4. Build a simple version first and then continue designing it.

### Colours

- [Coolors](https://coolors.co/) – generate colour palettes and copy colour codes
- [Happy Hues](https://www.happyhues.co/) – see colour palettes in example layouts

### Fonts

- [Google Fonts](https://fonts.google.com/) – find fonts and add them to websites

### Images

- [Pexels](https://www.pexels.com/) – find and download images

### Icons

- [Bootstrap Icons](https://icons.getbootstrap.com/) – find and download free SVG icons

You can save a downloaded icon in your project and use it like an image:

```html
<img src="images/heart.svg" alt="Heart">
```

## Help with HTML and CSS

- first, have a look at the previous `README` and `live` folders
- [A Complete Guide to Flexbox](https://css-tricks.com/snippets/css/a-guide-to-flexbox/) – the Flexbox overview from class
- [MDN Web Docs](https://developer.mozilla.org/en-US/docs/Web) – documentation and examples for HTML and CSS

If something is not working, check these things first:

- Are all files saved?
- Are the filename and path correct?
- Is the stylesheet linked correctly?
- Do the class name in the HTML and the selector in the CSS match?
- Is a bracket or semicolon missing?

## Using AI for Help

You can use AI, for example, to:

- collect ideas for your website
- get suggestions for colours or designs
- find errors in your code
- ask for explanations of unfamiliar code
- try animations or other new things

Specific questions are more helpful than “Build me a website”:

- “My CSS file is not loading. What should I check?”
- “Explain this code to me step by step.”
- “How can I animate this box when I hover over it?”
- “Give me three design ideas for a website about my hobby.”

- you have access to the following chatbots with your DCI accounts:
    - ChatGPT/Codex → from a simple chatbot to an agentic system for complex projects
    - Google Gemini → available as a standard chatbot; also useful for projects: [Google Stitch design tool](https://stitch.withgoogle.com/)

## Publish with GitHub Pages

1. Put the project in a public GitHub repository.
2. Make sure that the home page is called `index.html`.
3. Push your current version to the `main` branch.
4. On GitHub, open **Settings → Pages**.
5. Select **Deploy from a branch**, then `main` and `/root`.
6. Save the setting and wait a moment for your Pages link.
7. Open the link and share it in the course channel.

You can find detailed instructions in the [GitHub Pages Quickstart](https://docs.github.com/en/pages/quickstart).
