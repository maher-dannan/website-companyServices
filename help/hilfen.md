# Hilfen und Inspiration

## Aufbau einer Seite

Entscheidet euch für einen One-Pager oder eine Webseite mit Unterseiten. Ein möglicher Aufbau:

- **Kopfbereich** mit Titel oder Name
- **Einführung** mit kurzem Überblick oder großem Bild/Galerie
- **Hauptinhalt** mit Informationen
- **Kontakt oder Abschlussbereich**
- **Fußbereich** mit Zusatzinfos

## Inspiration für Webseiten

Schaut euch ein paar Webseiten an und achtet zum Beispiel auf:

- Welche Farben werden verwendet?
- Wie sind die Inhalte angeordnet?
- Wie viel Abstand ist zwischen den Elementen?
- Welche Schriften, Bilder oder Animationen fallen euch auf?

Ihr müsst keine ganze Webseite kopieren. Oft reichen schon ein Aufbau, eine Farbstimmung oder ein einzelnes Element als Inspiration.

- [One Page Love](https://onepagelove.com/inspiration) – Webseiten, die aus einer einzelnen Seite bestehen
- [Land-book](https://land-book.com/) – viele unterschiedliche Webseiten und Stile
- [SiteInspire](https://www.siteinspire.com/) – Webseiten nach Stil und Thema entdecken
- [Awwwards](https://www.awwwards.com/) – ungewöhnliche Designs, Effekte und Animationen

## Schnell zu einem Design kommen

1. Sucht euch eine Webseite als grobe Inspiration.
2. Entscheidet euch für eine Farbpalette.
3. Wählt eine Schrift und bei Bedarf Bilder oder Icons.
4. Baut zuerst eine einfache Version und gestaltet sie dann weiter.

### Farben

- [Coolors](https://coolors.co/) – Farbpaletten erzeugen und Farbcodes kopieren
- [Happy Hues](https://www.happyhues.co/) – Farbpaletten direkt in Beispiel-Layouts sehen

### Schriften

- [Google Fonts](https://fonts.google.com/) – Schriften suchen und in Webseiten einbinden

### Bilder

- [Pexels](https://www.pexels.com/) – Bilder suchen und herunterladen

### Icons

- [Bootstrap Icons](https://icons.getbootstrap.com/) – kostenlose SVG-Icons suchen und herunterladen

Ein heruntergeladenes Icon könnt ihr in eurem Projekt speichern und wie ein Bild verwenden:

```html
<img src="images/heart.svg" alt="Herz">
```

## Hilfe für HTML und CSS

- schaut zuerst in die bisherigen `README`- und `live`-Ordner
- [A Complete Guide to Flexbox](https://css-tricks.com/snippets/css/a-guide-to-flexbox/) – die Flexbox-Übersicht aus dem Unterricht
- [MDN Web Docs](https://developer.mozilla.org/de/docs/Web) – Dokumentation und Beispiele für HTML und CSS

Wenn etwas nicht funktioniert, prüft zuerst:

- Sind alle Dateien gespeichert?
- Stimmen Dateiname und Pfad?
- Ist das Stylesheet richtig verlinkt?
- Stimmen Klassenname im HTML und Selektor im CSS überein?
- Fehlt eine Klammer oder ein Semikolon?

## KI als Hilfe

Ihr könnt KI zum Beispiel nutzen, um:

- Ideen für eure Webseite zu sammeln
- Farb- oder Designvorschläge zu bekommen
- Fehler im Code zu finden
- euch unbekannten Code erklären zu lassen
- Animationen oder andere neue Dinge auszuprobieren

Hilfreicher als „Baue mir eine Webseite“ sind konkrete Fragen:

- „Meine CSS-Datei wird nicht geladen. Was soll ich überprüfen?“
- „Erkläre mir diesen Code Schritt für Schritt.“
- „Wie kann ich diese Box beim Darüberfahren animieren?“
- „Gib mir drei Designideen für eine Webseite über mein Hobby.“

- auf folgende Chatbots habt ihr mit euren DCI Accounts Zugriff:
    - Chatgpt/Codex -> einfacher Chatbot bis hin zu agentischem System für komplexe Projekte
    - Google Gemini -> als gewöhnlicher Chatbot und für Projekte interessant: [Design Tool Google Stitch](https://stitch.withgoogle.com/)

## Mit GitHub Pages veröffentlichen

1. Legt das Projekt in einem öffentlichen GitHub-Repository ab.
2. Achtet darauf, dass die Startseite `index.html` heißt.
3. Pusht euren aktuellen Stand auf den `main`-Branch.
4. Öffnet auf GitHub **Settings → Pages**.
5. Wählt **Deploy from a branch**, dann `main` und `/root`.
6. Speichert die Einstellung und wartet kurz auf euren Pages-Link.
7. Öffnet den Link und teilt ihn im Kurskanal.

Die ausführliche Anleitung findet ihr im [GitHub Pages Quickstart](https://docs.github.com/en/pages/quickstart).
